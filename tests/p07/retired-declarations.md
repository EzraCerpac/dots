# Retired-declaration scenario inventory

P-07 accounts for all 11 cases in `tests/test_retired_declarations.mjs`, including their nested variants. The legacy file is byte-identical in the base checkout and the staged v0.4.0 oracle. The executable suite in `tests/retired_declarations.rs` has 11 `unchanged_` tests and one `new_` test. The table identifies every translated case and the legacy helper assertions replaced by executable observations. The tests carry a P-08 ignore marker for the Rust sync implementation. See `plan/plan.md:192,198` and `docs/contract.md:887–893`.

Source equality means equality of decoded TOML strings across basic, literal, triple-basic and triple-literal quoting. Quoting and TOML escapes can encode the same value. Path normalization, case folding, slash conversions, tilde expansion and substring matching do not participate. A backslash in a TSV source is still refused. The new triple-quote test documents the one changed behavior in the 11 legacy cases and is outside unchanged-oracle parity.

The legacy suite uses imported helpers and an injected source-existence callback. The Rust cases invoke `dots sync` on the executable selected by the harness. Real Git creates a separate bare local remote and peer clone per fixture; the peer adds the retirement list and retains or removes the tracked source according to the case. The Rust executable receives a file URL directly. The JavaScript oracle receives a GitHub-shaped origin redirected to the same real file transport by fixture-local Git URL configuration. File-only Git transport keeps both runs local. A scanner double writes an empty gitleaks report. Real mise runs with offline settings and a private home, system config and temp directory. The tests assert the checked-out state and file effects where the legacy helpers exposed internal return values.

Every executable refusal requires native validation to accept the fixture and sync to advance to the incoming commit. The P-08 parser checks above preserve the variants that cannot establish that boundary through native mise.
